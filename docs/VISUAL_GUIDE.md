# 🎬 Visual guide

All four GIFs are generated by `Code/animate.py` from the scalar known-graininess recurrence implemented in `Code/tsmc/control.py`. They are scientific illustrations of the stated parameter choices, not measurements or network simulations.

| Asset | Domain and parameters | Interpretation |
|---|---|---|
| `header.gif` | Harmonic scale, alpha = 0.5; r0 = 1 | Decorative heading with a computed discrete radius plot |
| `graininess.gif` | Harmonic, square-root and geometric scales | Contrasts vanishing graininess with growing gaps |
| `accumulation.gif` | t_k = 1 − 0.72^k, r0 = 0.5 | Finite prefix plus a separately marked exact limiting state |
| `mixed.gif` | Union of [n,n+0.6], r0 = 0.8 | Dense flow and empty gaps; first four cells |

All animations use U = 1 and D = 0.2. The geometric comparison starts at r0 = 0; its ratio is 1.12. Other comparison panels start at r0 = 1. The header and comparison have different finite-prefix lengths.

For the accumulation example, h_k = 0.28(0.72)^k. The radius after n steps is the maximum of the initial-state term r0 − (U−D)t_n and the disturbance-memory terms D h_j − (U−D)(t_n−t_{j+1}). At the limit t = 1, the first term is −0.3; each fixed-j memory term is negative since 0.2(0.28) < 0.8(0.72). Terms from j approaching infinity tend to zero. Hence the limiting radius is zero.

The mixed-scale gap is 0.4, so its disturbance floor at the next interval entrance is 0.08. The dense intervals have length 0.6 and use slope −0.8 until the radius reaches zero. No line joins the endpoints across a gap.

## Accessibility and display

Each GIF has descriptive alternative text in the README. GIFs loop automatically; GitHub does not provide a dependable inline pause control. The equations, captions and atlas provide a static reading route. All assets are local, except the optional remotely rendered badges. GitHub does not run JavaScript in README files.

## Publishing

Create a GitHub repository and upload the contents of this folder, placing `README.md` at the repository root. Preserve the relative `assets/` paths. No repository URL has been assumed, and this package does not publish anything automatically.
